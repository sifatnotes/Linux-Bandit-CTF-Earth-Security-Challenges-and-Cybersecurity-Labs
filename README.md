## Categories

- **Linux fundamentals:** Bandit levels 3–7 and command-line problem-solving.
- **Security utilities:** Sysinternals tools and system investigation.
- **Cryptography concepts:** XOR and cipher-related challenges.
- **Defensive security:** Command injection prevention and privilege escalation defenses.
- **Secure communications:** Messaging and information protection.
- **Network analysis:** Traffic traces and security investigation.

## Learning Path

1. Begin with the Bandit level challenges to build Linux command-line familiarity.
2. Explore Sysinternals utilities to understand system inspection and troubleshooting.
3. Study the Earth cipher and XOR challenges to explore cryptographic concepts.
4. Review command injection and root escalation prevention from a defensive perspective.
5. Finish with secure messaging and traffic-trace investigations.

Adjust this sequence to match each lab's prerequisites and difficulty.

## How to Use the Labs

1. Choose a lab from the index.
2. Open its original Learn SecByte page and review the objectives.
3. Follow the provider's instructions in an authorized environment.
4. Record your observations, tools, and lessons learned.
5. Practice explaining both the security issue and the relevant mitigation.
